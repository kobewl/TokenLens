## 编辑器原始记忆

- 启动后自动发现本机编辑器记忆，按编辑器独立列出来源。
- 支持 Claude Code、Codex 的原生文件记忆，以及 Gemini、Cursor、Kiro、Windsurf 等工具的本机规则文件。
- 查看单份原文、搜索文件或项目、区分全局与项目范围。
- 默认不汇总。只有点击“汇总选中记忆”后，才按选中来源生成可编辑汇总。

## 手动同步

- 单份记忆和选中汇总都可同步到目标编辑器的项目规则文件。
- 写入前预览文件前后差异；确认后备份原文件并保留标记区块之外的内容。
- 支持撤销本次同步；来源或目标已变化时停止写入。
- 修改项目 AGENTS.md 需要明确勾选允许。

## 使用说明

- 本机记忆与手动项目交接是两个独立入口，不会自动相互导入。
- 扫描不读取云端记忆，也不会自动上传内容或写入编辑器。
- 云端记忆和未公开的私有格式尚未适配；ZCode 当前用于发现最近项目目录。
