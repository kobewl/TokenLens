## 新功能

- 在设置中检查新版本，查看版本说明并下载安装。
- 启动时可自动检查更新；发现新版后轻量提醒，安装由你确认。
- 更新下载显示实时进度，安装完成后可选择立即重启或稍后重启。
- 更新后的首次启动展示本版新功能，设置中可随时重新查看。

## 发布与安全

- GitHub Actions 自动构建 Apple Silicon 和 Intel 安装包。
- 正式发布生成签名更新包、校验值和更新清单。
- 更新包必须通过签名验证才能安装。

## 使用提示

- 正式安装请将 TokenLens 拖入“应用程序”后运行。
- 本地统计和项目记忆继续保存在原位置。
- 当前安装包尚未使用 Apple Developer 签名或公证，macOS 首次启动可能需要在“隐私与安全性”中允许打开。
