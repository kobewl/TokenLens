## 全新的界面与导航

- 默认进入「概览」：今日 Token 与请求（对比昨日全天）、近 7 日、近 14 天按模型堆叠的趋势、今日工具占比、近 26 周活跃度热力图，以及自动生成的洞察。
- 导航重新分组：概览 / 用量统计 / 工具与来源，以及「记忆」下的项目交接、编辑器记忆；设置固定在底部。侧边栏可折叠，窗口较窄时自动收起。
- 命令面板 `⌘K`：跳转页面、立即同步、添加项目、切换主题、预设用量筛选、切换项目。
- 快捷键：`⌘1`–`⌘5` 切换页面，`⌘,` 打开设置，`⌘R` 立即同步。
- 反馈改为轻量提示，不再在页面里长期保留提示条；正文字号整体放大，图标统一，浅色 / 深色 / 跟随系统。

## 用量统计

- 工具 chips + 时间范围筛选，筛选在概览和工具页之间跳转时保持一致。
- Token 构成条、按模型堆叠趋势图（悬停查看明细）、请求日志与模型 / 工具 / 供应商 / 项目页签。
- 新增「估算花费」：在「设置 → 估算定价」中按每百万 Token 填写模型单价后显示。TokenLens 不内置价目表，未填写的模型显示「未定价」。

## 菜单栏（macOS）

- 菜单栏显示今日 Token，菜单中可查看最常用工具、立即同步、打开主窗口。数字与概览页同一口径。
- 可选「关闭窗口后继续在菜单栏运行」，窗口隐藏期间每分钟同步一次。默认关闭，行为与之前一致。
- 清空本地用量后菜单栏数字同步归零。

## 其他

- 浏览器预览显示明确标注的虚构演示数据，不再是空白页。
- 编辑器记忆与项目交接沿用原有能力，界面与新设计统一。
- 隐私不变：只保存用量元数据，不保存提示词、回答或密钥。
